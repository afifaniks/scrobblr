Scrobblr

Auto-scrobble music videos you watch on YouTube.

1 Last.fm API credentials

Create an API account at last.fm/api/account/create, then paste the key and shared secret here. Use any Callback URL (it isn't used by this extension).

2 Connect your account

Not connected

A Last.fm window opens — click Yes, allow access and it connects automatically. If Last.fm rejects the callback, set your API app's Callback URL to: …

3 Categories to scrobble

Only videos whose YouTube category is in this list get scrobbled. Music and Entertainment are on by default.

4 Title cleanup words

Words or phrases to strip from video titles when working out the artist and song — on top of the built-in list (Official Video, Lyrics, Remastered, …). Handy for tags like Sped Up, 8D Audio, or Slowed + Reverb. Matching is case-insensitive.

Built-in — always applied

Behaviour

A track is scrobbled once it has been actively played for this long, or when the video finishes — whichever comes first. Default is 60 seconds. (Pauses and seeks don't count toward this time.)

Your credentials and session stay in this browser's local storage.
